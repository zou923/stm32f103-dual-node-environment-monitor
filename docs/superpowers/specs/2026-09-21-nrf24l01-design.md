# NRF24L01 bidirectional communication design

## Goal

Add a HAL-based NRF24L01 module that transmits temperature, humidity and
illuminance every second and receives compact remote-control commands.

## Hardware contract

- SPI1: PA4 CSN, PA5 SCK, PA6 MISO, PA7 MOSI.
- PB10 is CE; PA10 is the active-low IRQ input.
- NRF24L01 uses 3.3 V only, with the existing local 10 uF and 100 nF capacitors.

## Protocol

- RF channel 76, 1 Mbps, auto acknowledgement and auto retry.
- Five-byte address `NODE1` for this board.
- Telemetry packet: packet type `0x01`, temperature tenths (signed 16-bit),
  humidity tenths (unsigned 16-bit), illuminance (unsigned 16-bit), status byte.
- Command packet: packet type `0x10`, command byte, argument 16-bit.

## Module boundaries

- `Hardware/NRF24L01/NRF24L01.c/.h`: SPI register access, initialization,
  telemetry transmit and received-command polling.
- `Core/Src/main.c`: calls initialization once, sends telemetry after each
  successful sensor refresh, and consumes any received command without
  disrupting display or LED scheduling.

## Failure behavior

No wireless device, an absent acknowledgement or an invalid command must not
block the PC13 loop. The module returns finite status values.
