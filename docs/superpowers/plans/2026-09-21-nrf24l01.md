# NRF24L01 implementation plan

**Goal:** Add HAL SPI1 NRF24L01 telemetry transmission and command reception.

**Spec:** `docs/superpowers/specs/2026-09-21-nrf24l01-design.md`

### Task 1: HAL SPI1 and NRF24L01 module

- Create `Hardware/NRF24L01/NRF24L01.c/.h`.
- Configure SPI1 on PA5/PA6/PA7, PA4 CSN, PB10 CE and PA10 IRQ.
- Implement bounded register access, channel 76, address `NODE1`, auto ACK,
  telemetry transmit and command receive APIs.
- Add HAL SPI source to `CMakeLists.txt`; build the ARM ELF.

### Task 2: Application telemetry

- Modify `Core/Src/main.c` to initialize NRF24L01 once.
- Send sensor values after every one-second refresh and poll commands in the
  main loop without blocking PC13.
- Build and flash through the existing DAP script; require `Verified OK`.
