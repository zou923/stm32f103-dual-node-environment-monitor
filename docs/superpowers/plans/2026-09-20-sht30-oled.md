# SHT30 OLED display implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read the SHT30 every second and display temperature and humidity on the OLED.

**Architecture:** Extract PB6/PB7 setup plus bounded addressable I2C1 transfers into a shared module. Keep OLED command/data handling in its port module; add a separate SHT30 module for command, CRC validation and fixed-point conversion. `main.c` schedules OLED refresh and PC13 blink independently.

**Tech Stack:** C, STM32F1 SPL, I2C1, SHT30, SSD1306, CMake/Ninja, CMSIS-DAP/OpenOCD.

**Spec:** `docs/superpowers/specs/2026-09-20-sht30-oled-design.md`

## Global Constraints

- PB6 = I2C1 SCL and PB7 = I2C1 SDA; both OLED and SHT30 share the bus.
- OLED address is `0x3C`; SHT30 address is `0x44`.
- SHT30 uses `0x2C06`, validates both CRC-8 bytes, and returns tenths without floating point.
- I2C waits are finite; read failure renders `SHT30 ERROR` and cannot permanently stop PC13.
- OLED refreshes about once per second; PC13 remains at 500 ms.

## Review Focus

- Bad SHT30 CRC must produce an error result rather than incorrect displayed values; covered by Task 2 source test.
- Absent SHT30 acknowledgement must leave bounded transport paths and permit the PC13 loop; covered by Task 1 source test.
- The 0 °C and negative-temperature conversion path must retain its sign and decimal digit; covered by Task 2 source test.
- I2C bus initialization must happen once in the shared transport, rather than per OLED/SHT30 transaction; covered by Task 1 source test.
- OLED and SHT30 addresses must remain distinct on the shared PB6/PB7 bus; covered by Task 3 source test.

### Task 2: SHT30 driver

**Files:**
- Create: `Hardware/SHT30/SHT30.c`
- Create: `Hardware/SHT30/SHT30.h`
- Create: `tests/verify-sht30.ps1`

**Interfaces:**
- Consumes: `I2C1_Init`, `I2C1_Write`, `I2C1_Read` from Task 1.
- Produces: `void SHT30_Init(void)` and `int SHT30_Read(int16_t *temperature_tenths, uint16_t *humidity_tenths)`; returns `1` only when both CRC values validate.

- [ ] Write `verify-sht30.ps1` requiring address `0x44`, command bytes `0x2C/0x06`, a CRC-8 function using polynomial `0x31` with initial `0xFF`, six-byte sample handling, both CRC comparisons, and integer conversion constants `1750`, `450`, and `1000`; run and observe failure because SHT30 files do not exist.
- [ ] Implement `SHT30_Init` as a call to `I2C1_Init`. Implement `SHT30_Read`: write `{0x2C,0x06}`, wait a finite 20 ms conversion period, read six bytes, validate bytes 2 and 5 against each pair, then calculate `temperature_tenths = (1750 * raw_temperature) / 65535 - 450` and `humidity_tenths = (1000 * raw_humidity) / 65535`.
- [ ] Run `powershell -NoProfile -ExecutionPolicy Bypass -File tests/verify-sht30.ps1; cmake --build build`; expect checks and build to pass.
